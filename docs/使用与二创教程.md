## 第 0 章 · 认识这个项目

### 它是什么

上游 [breeze-devs/Settlements-Alpha](https://github.com/breeze-devs/Settlements-Alpha) 是一个「增强村庄体验」的 Minecraft 模组。本二创在它的基础上，把**村庄建造**这件事做成了看得见的过程：

- 世界生成时按村庄规模铺满**整村山东三合院**；
- 房子**完美贴地**（不再悬空或陷进地里）；
- 每栋房有**天花板**、青瓦坡顶、真实几何家具；
- 院落之间是**井字形石板村道**；
- 建造时 **8 个村民手持当前方块站在工地边，逐格把房子搭起来**。

再叠加机械动力（Create）能力：交易换房自动选址建造、建并运转工厂、扩建村庄、修铁路、造火车与火车站、地形修补、搭建飞艇；以及按人口自动 **村庄 → 小镇 → 城市** 升级。

## 第 1 章 · 五分钟上手（玩家路线）

### 1.1 准备环境

| 组件 | 要求 | 说明 |
| --- | --- | --- |
| Java | **21** | NeoForge 1.21.1 需要 JDK 21 |
| 启动器 | HMCL 3.5+（实测 3.16.4） | 也可用官方启动器 |
| 游戏 | Minecraft **1.21.1** | |
| 加载器 | **NeoForge 21.1.259** | 与项目 `gradle.properties` 一致 |
| 内存 | **建议 3 GB** | 实测 8 GB cgroup 下自动分配 16 GB Xmx 会 OOM 被杀，手动调到 3072 MB 后稳定 |
| 账号 | 离线账号即可 | 实测用 `SettlementsTest` |

> 无 GPU 的软件渲染（llvmpipe / Xvfb）环境帧率会很低，属正常现象，不影响功能验证。

### 1.2 拿到整合包

去 [Releases](https://github.com/hhxrr/settlements-erchuang/releases/tag/v3.0.0) 下载 **`WanJiaYanHuo-3.0.zip`**，解压后先读 `00_从这里开始.md`。

> 为什么资产名是拼音？GitHub 的 Release 资产名会强制剥离中文字符（`万家烟火3.0.zip` 会被净化成 `3.0.zip`），所以 Release 用 `WanJiaYanHuo-3.0.zip`；**解压后的顶层目录就是 `万家烟火3.0/`**，中文名完整保留。

### 1.3 安装 Mods（核心一步）

把整合包 `mods/` 里的 **全部 6 个 jar** 复制到游戏实例的 `mods/` 目录：

| jar | 作用 | 是否必需 |
| --- | --- | --- |
| `settlements-1.0.0-beta.nightly-110126-机械动力改造.jar` | **本二创主体** | 必需 |
| `create-1.21.1-6.0.10.jar` | 机械动力，供料/机械/蓝图 | **必需** |
| `create-aeronautics.jar` | 航空学（飞艇/船） | 可选 |
| `createdieselgenerators.jar` | 柴油动力 | 可选 |
| `sable-neoforge-1.21.1-2.0.6.jar` | 航空学物理/渲染依赖 | 装航空学则必需 |
| `struts-1.3.1.jar` | 柴油动力可选依赖 | 可选 |

> **Create 缺失 = 本 Mod 直接不加载**（写死在 `neoforge.mods.toml` 的 `[[dependencies]]`）。航空学/VS2 缺失只是关闭飞艇支线，其余能力齐全。

### 1.4 首次启动验收清单

按顺序确认，任何一步不对就别往下走：

1. 启动器主菜单角标显示 **`Minecraft 1.21.1 / NeoForge 21.1.259`** 与 mods 数量（实测 15 mods）；
2. Mods 列表里能筛出 **`Settlements 1.0.0-beta.nightly-110126`**、Create、航空学、柴油动力；
3. 新建/进入世界，日志出现 `Settlements initialized`，数据包正常加载；
4. 创造模式，开聊天栏输入 `/time set noon` 切白天，方便观察。

## 第 2 章 · 看效果：演示命令速查

所有演示命令由 `/scaledemo` 提供，需要**单人世界开启作弊**或管理员权限（命令默认权限等级 2）。

### 2.1 第一件事：看村民逐格搭三合院

```text
/time set noon
/scaledemo yard
```

`/scaledemo yard` 会在镜头前重建**单个三合院**。你会看到：

- **8 个真实村民**贴地站在工地外圈，手持**当前正在放置的方块**并挥臂，`ItemDisplay` 在手侧同步显示该方块；
- 建造队列**按 y 从低到高排序**，所以顺序是 **地板 → 墙 → 天花板 → 青瓦坡顶** —— 在盖屋顶之前能亲眼看到天花板封顶；
- 速度 **6 格/tick**，单个院落约 **2359 格**，全过程约 **12 秒**，看得清「逐格生长」。

想拍干净画面：站远一点用斜视角，按 **F1** 隐藏 HUD。

### 2.2 命令全表（源码实测）

| 命令 | 作用 | 输出示例 |
| --- | --- | --- |
| `/scaledemo yard` | 近景：单个三合院逐格搭建 | `[scaledemo] 单个三合院：村民逐格搭建 2359 格` |
| `/scaledemo village` | 整村山东三合院民房，贴地重建 | `[scaledemo] 整村三合院民房：贴地重建 N 格` |
| `/scaledemo town` | 全村拆除重建 → 小镇 | `[scaledemo] 全村拆除重建 → 小镇：N 格` |
| `/scaledemo city` | 全城拆除重建 → 城市砖瓦街区 | `[scaledemo] 全城拆除重建 → 城市砖瓦街区：N 格` |
| `/scaledemo status` | 查看当前搭建队列进度 | `[scaledemo] 待搭建方块: N，施工村民: N` |

> `town` / `city` 是「全村/全城拆除重建」，会改动大片地形，建议先在测试存档里跑，别在主力存档用。

### 2.3 一次完整的观赏流程

```text
/time set noon          # 白天
/scaledemo yard         # 近景看村民逐格搭建（约 12 秒）
/scaledemo status       # 期间可查队列剩余格数
/scaledemo village      # 退到高空俯视，看整村铺开
/scaledemo town         # 看升级成小镇
/scaledemo city         # 看升级成砖瓦城市
```

看全景用高空俯视（如 `/tp @s 213 -15 -262 0 88` 这类坐标按实际地形调整），能看到成片青瓦顶院落 + 井字石板道路。

## 第 3 章 · 玩法：让村民真的替你盖房

演示命令是「一键看效果」；真正和村民互动要走交易路线。

### 3.1 三个新职业与工作站方块

| 职业 | 工作站方块 | 主要能力 |
| --- | --- | --- |
| **建筑师** | `settlements:architect_station`（建筑绘图台） | 建房 / 扩建 / 铁路 / 飞艇 |
| **工厂工人** | `settlements:factory_station`（操作台） | 机械 / 拆除 / 工厂 |
| **机械师** | `settlements:mechanic_station`（机械台） | 火车 / 火车站 / 地形修补 |

工作站方块已注册为 **POI**，村民站在附近即可认领职业。方块可在**创造标签页**取，或由 `BuildTrainStationBehavior` 在村中放置。

### 3.2 上岗与下单

```text
# 1) 拿工作站方块（创造模式）
/give @s settlements:architect_station

# 2) 把方块放在村民附近，等他认领职业

# 3) 右键村民打开交易菜单，用绿宝石购买订单
```

计价遵循 **1 方块 = 1 绿宝石** 的等价原则：HOUSE 按 `HandHousePlan.costInBlocks()` 的房屋方块数算，其余取固定预估值。

### 3.3 订单类型

| 订单 | 职业 | 村民会做什么 |
| --- | --- | --- |
| 建房订单 | 建筑师 | 自动找空地 → 逐格建造 |
| 扩建订单 | 建筑师 | 在村庄边缘增建（可多次购买） |
| 铁路订单 | 建筑师 | 定位最近的非废弃、非僵尸村庄并铺铁轨 |
| 工厂订单 | 工厂工人 | 建 Create 加工厂（安山岩外壳 + 创造板条箱 + 动力源 + 压力机/搅拌机） |
| 火车订单 | 机械师 | 就近铺铁轨并搭出一列火车 |
| 火车站订单 | 机械师 | 整平地面建站，站中央放机械师工作站 |
| 地形修补订单 | 机械师 | 填坑、整平、清悬空残骸 |
| 搭建飞艇 | 建筑师 | **仅装航空学时出现**，强力胶浇固 → 物理化 → 可操控 |

购买后村民背包出现订单，会自动找空地开始干活。

### 3.4 供料

村民身边 `CRATE_RADIUS` 范围内有**创造板条箱**即无限供料（`consumeOrBypassed`）；否则消耗村民背包里的方块。想让大型建造不中断，就在工地旁放一个创造板条箱。

## 第 4 章 · 验收：怎么确认功能都在

### 4.1 物品注册验证

```text
/give @s settlements:dialogue_manual        # Gave 1 [对话手册]
/give @s settlements:build_order            # Gave 1 [建房订单]
/give @s create:mechanical_press            # Gave 1 [Mechanical Press]
/give @s createdieselgenerators:diesel_engine  # Gave 1 [Diesel Engine]
/give @s aeronautics:andesite_propeller     # Gave 1 [Andesite Propeller]
```

能给出物品即说明对应 Mod 与本二创的物品注册生效。

### 4.2 家具模型验证

在草地上摆一排，斜视角看是否是**真实立体几何**（不是一整块木板、也不是紫黑缺失材质）：

```text
/setblock ~ ~ ~ settlements:folding_chair
/setblock ~2 ~ ~ settlements:folding_chair
/setblock ~4 ~ ~ settlements:folding_table
/setblock ~6 ~ ~ settlements:tea_set
/setblock ~8 ~ ~ settlements:fan
/setblock ~10 ~ ~ settlements:playing_cards
```

预期：两个 **X 形交叉腿折叠凳**（帆布座面 + 前后 X 支架 + 横撑 + 脚垫）、折叠桌、茶壶茶杯木托盘、折扇、三张错开摊开的扑克牌。

### 4.3 画面验收点

- 俯视整村：成片青瓦顶三合院 + 井字石板道路，**无蓝色/黑色未加载空洞**；
- 房屋**贴地**，不悬空、不遁地；
- 家具模型无紫黑缺失材质；
- 晴天白天，按 F1 后画面无 HUD/聊天框。

## 第 5 章 · 从源码构建（开发者路线）

### 5.1 克隆与目录

```bash
git clone https://github.com/hhxrr/settlements-erchuang.git
cd settlements-erchuang
```

| 路径 | 内容 |
| --- | --- |
| `src/main/java/dev/breezes/settlements/` | 全部源码（1852 个 Java 文件） |
| `src/main/resources/assets/settlements/` | 材质、模型、语言文件 |
| `src/main/resources/assets/settlements/models/block/` | 家具 JSON 模型 |
| `presentation/commands/SettlementScaleDemo.java` | 演示命令 + 逐格搭建调度 |
| `compat/create/build/ShandongHousePlan.java` | 三合院蓝图 |
| `README_机械动力改造.md` | 七轮改造全记录 |
| `NOTICE.md` | 二次创作与协议声明 |

### 5.2 依赖准备

需要**完整的** Create 6.x (mc1.21.1) jar 放到 `libs/`：

```bash
cp /path/to/create-1.21.1-6.0.10.jar libs/
```

> 仓库不分发第三方 jar（体积大且各有独立许可），`libs/` 被 `.gitignore` 排除。想启用飞艇/船，再装 `create_aeronautics` 与 `valkyrien_skies`。

### 5.3 构建

```bash
./gradlew build        # 产出 build/libs/settlements-*.jar
```

把产物丢进整合包 `mods/` 即可进世界测试。

### 5.4 关于沙箱里的离线编译链（重要背景）

改造过程中，沙箱里 Gradle 的注解处理链（**Lombok + Dagger 在 JDK 21 下顺序冲突**）整体失效，NeoForge 的 `createMinecraftArtifacts` 反编译也曾因内存不足失败。为打通编译，实际用了离线编译链：

1. 用 HMCL 实例里的 133 个 libraries 补齐 NFRT recompile 依赖，跑通反编译与 5364 个 Minecraft 源文件重编译；
2. 用 **delombok** 把 1545 个源文件展开为纯 Java，再用 **`javac -proc:full`** 单独跑 Dagger，绕开注解处理顺序冲突；
3. 补齐 NeoForge universal/client、Create、以及 Create jarJar 内嵌的 Registrate 到 classpath；
4. 修复 1.21.1 API 变更、Dagger 作用域冲突、Create 字段改名等约 60 处编译问题。

**你在本机有网、有完整 Create 的正常环境里，直接 `./gradlew build` 即可**，不需要复现这套离线链。最终产物以 jarJar 内嵌了 Dagger 运行时依赖。

## 第 6 章 · 二创改造地图

想继续改，按下面这张表定位文件。七轮改造的完整动机与代码细节见 `README_机械动力改造.md`。

| # | 改造 | 关键实现 | 要点 |
| --- | --- | --- | --- |
| 1 | **整村山东民房** | `ShandongVillageGenerator` | 世界生成时按村庄规模铺院落 |
| 2 | **完美贴地** | `terrainTopY()` in `SettlementScaleDemo` | 旧版用玩家/钟**单点** `getHeight()` 当整个半径 56/62 圆范围的统一 Y，房屋/钟楼把 heightmap 抬到屋顶 → 整片悬空。新算法在村庄结构**之外 8 方向采样空地取中位数**；清挖从 `terrainY+1` 起（绝不挖地面），地板正好落在 `terrainY+1` |
| 3 | **三合院** | `ShandongHousePlan.java`（重写） | 15×15 院落：南面门楼，正房（两层变体）+ 西厢房 + 东厢房，中庭 + 石板甬道，青灰石砌院墙带瓦顶压顶 |
| 4 | **天花板** | `MockBlueprintLibrary.townHouse()/urbanBlock()` | 墙顶铺整片云杉木平整顶棚；**放置队列按 y 从低到高排序**，逐格搭建时天花板在盖屋顶前铺好 |
| 5 | **真实材质** | `assets/settlements/models/block/*.json` | 家具从 `cube_all` 木板盒改为纯 JSON 几何（复用原版贴图，无需新 PNG）；房屋换青灰石砖墙/泥砖墙裙/木圈梁/`deepslate_tiles` 青瓦/青色屋脊/玻璃窗/实木门/砖烟囱 |
| 6 | **井字村道** | `enqueueRoads()` | 抛光安山岩亮色中心 + 圆石路缘 + 石砖十字路口 + 砂砾变化 + 交叉口灯笼路灯；网格步长与三合院占地对齐 |
| 7 | **村民逐格搭建** | `updateBuilders()` + `ItemDisplay` | 8 个真实村民手持当前方块挥臂、随进度移动；`blocksPerTick = 6` |

### 两个真实踩过的坑（改代码时别再踩）

- **村民被墙挡住 / 遁地**：最初把村民生成在建筑内部，被墙挡住；后来 `updateBuilders` 每 tick 重新采样地形高度，采样点落在被挖空的坑里返回偏低值，村民被重力拽到 `y=-61`。最终解法：**用缓存的施工点地形高度**（不再每 tick 重采样）+ `setNoGravity(true)` + 站位半径收近到 9 + 站在 `center.y+2`（地板之上、与家具同层）。
- **房屋悬空**：见上表第 2 行，根因是单点 heightmap，必须用 8 方向中位数。

## 第 7 章 · 常见问题 FAQ

| 现象 | 原因 | 解法 |
| --- | --- | --- |
| 游戏里 Mods 列表**没有 Settlements** | Create 缺失 | 装上 `create-1.21.1-6.0.10.jar`，它是必需依赖 |
| 首次进世界**被系统杀掉 / 闪退** | 启动器自动分配 16 GB Xmx，超过容器上限 | 手动把内存设为 **3072 MB** |
| 画面**很卡** | 无 GPU 软件渲染（llvmpipe） | 正常现象；降低分辨率/视距，或换有 GPU 的环境 |
| 命令提示**无权限** | 命令默认权限等级 2 | 单人世界开启作弊，或用管理员/OP 权限 |
| 房子**悬空 / 陷进地里** | 旧版 bug | 本项目已修（`terrainTopY()` 8 方向中位数），确认用的是本二创 jar |
| **看不到村民** | 村民被生成在建筑内 / 遁地 | 本项目已修（缓存贴地高度 + 关闭重力 + `center.y+2`），确认用的是本二创 jar |
| 家具是**紫黑格子** | 缺失材质 | 本项目家具复用原版贴图，若出现说明 jar 内 `assets/` 不完整，重新构建 |
| `/scaledemo` 只改了一小块 | 命令本就分级 | `yard`=单院、`village`=整村、`town`/`city`=全镇/全城重建 |
| Release 资产名**不是中文** | GitHub 强制剥离资产名中的非 ASCII | 中文名在 Release 标题、说明、README、zip 内顶层目录里；下载后本地可随意改名 |
| 飞艇交易**不出现** | 未装航空学 / VS2 | 装上 `create-aeronautics`、`valkyrien_skies`；其余功能不受影响 |
